## Export tips

- **PNG** for stills (no JPEG compression on text UI).
- **GIF** ≤ ~4MB or **MP4** for motion; GitHub embeds both in README.
- Crop status-bar noise if it distracts; keep the floating profile chip.
- Same device + same scale for every still so the gallery feels coherent.
